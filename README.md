# 총성 인식 기반 거리/방향 추정 시스템
분대 단위 보급이 가능한 저비용 총성 탐지기 (캡스톤 디자인)

## 프로젝트 개요
마이크 3개로 총성을 수신하고, AI(CNN)가 소리를 분류한 뒤, TDoA(Time Difference of Arrival)로 거리와 방향을 추정하는 시스템

## 파일 설명

### 데이터 전처리
| 파일 | 설명 |
|------|------|
| `organize_data.py` | ESC-50 데이터셋을 임펄스/비임펄스 2분류로 자동 분류 |
| `organize_data_v2.py` | ESC-50 데이터셋을 탐지 대상/사람 소음/배경음 3분류로 분류 |
| `record_samples.py` | 노트북 마이크로 배경음/말하기/박수/책상치기 소리를 직접 녹음하는 도구 |

### AI 모델 학습
| 파일 | 설명 |
|------|------|
| `train.py` | CNN 모델 v1 — ESC-50 데이터로 2분류 학습 (정확도 66.7%) |
| `train_v2.py` | CNN 모델 v2 — 데이터 증강 적용 (정확도 90.3%) |
| `train_v3.py` | CNN 모델 v3 — 3분류로 전환 (정확도 79.6%) |
| `train_v4.py` | CNN 모델 v4 — 팀원 데이터 추가 (정확도 89.8%) |
| `train_v5.py` | CNN 모델 v5 — 노트북 녹음 데이터 추가 (정확도 87.5%) |
| `train_v5b.py` | CNN 모델 v5b — ESC-50 + 노트북 녹음만 (정확도 78.2%) |

### 테스트 및 실행
| 파일 | 설명 |
|------|------|
| `test.py` | 마이크 연결 확인 및 3초 녹음 테스트 |
| `file_test` | 저장된 .wav 파일로 AI 모델 성능 검증 |
| `realtime_detect.py` | 마이크로 실시간 소리 분류 (다중 조건 판별 적용) |

### 거리/방향 추정
| 파일 | 설명 |
|------|------|
| `tdoa_simulation.py` | TDoA 기반 거리/방향 추정 시뮬레이션 (오차 0.00m 달성) |
| `integrated_system.py` | AI 탐지 + TDoA 계산 통합 시스템 |

### 이론 분석
| 파일 | 설명 |
|------|------|
| `sampling_vs_tdoa.py` | 샘플링 레이트별 TDoA 정밀도 이론 분석 (48kHz 채택 근거) |

## 개발 환경
- Python (Miniconda)
- TensorFlow / Keras (CNN 모델)
- librosa (오디오 분석)
- 데이터셋: ESC-50 + 팀원 제공 데이터 + 노트북 녹음

## 시스템 구조
```
소리 발생 → 마이크 3개 수신 → AI 분류(총성?) → TDoA 거리/방향 계산 → 결과 출력
```
